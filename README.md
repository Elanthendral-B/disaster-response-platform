# 🚨 Disaster Response Platform

A simple web platform designed to help people report disasters, request rescue support, and share information about missing persons during emergency situations.

The main goal of this project is to make emergency communication easier and faster through a clean and simple interface.

## 🌐 Live Website

https://disaster-response-26.netlify.app/

## 📌 About the Project

During a disaster or emergency, people may need help quickly. This platform provides a simple way for users to submit important information such as disaster reports, missing person details, and rescue requests.

I created this project as a frontend development project with a focus on simple design, easy navigation, and user-friendly forms.

## ✨ Features

* 🚨 Report a Disaster
* 🆘 Request Rescue Support
* 👤 Report a Missing Person
* 📍 Add location and emergency details
* 📝 Simple and easy-to-use forms
* 📱 Responsive design for different screen sizes
* 🎨 Clean and user-friendly interface
* ⚡ Fast frontend experience

## 🚀 Getting Started

To run this project on your computer:

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

```bash
cd disaster-response-platform
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The project will run locally using the Vite development server.
